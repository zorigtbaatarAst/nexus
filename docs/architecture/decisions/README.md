# Decisions

Architecture Decision Records for the engineering-intelligence-layer redesign.

**Numbering continues the existing sequence.** ADR-001 … ADR-021 live as `## ADR-0NN` sections
of [`docs/architecture-decisions.md`](../../architecture-decisions.md); records here start at
**ADR-022**. Two ADR-001s in one project is a confusion that costs real time to unpick, so the
sequence is shared even though the storage is not.

New records in this directory are one file each; the original twenty-one stay where they are.
Cite either form as `ADR-0NN` — that is what the rest of the repo already does.
